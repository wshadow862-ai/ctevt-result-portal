# CTEVT Quick Result & Marksheet Portal

This complete project package contains everything needed to run a fast, searchable CTEVT result portal backed by a MongoDB database and an automated PDF Notice Parser.

## Deployment Steps on GitHub & Render/Vercel:
1. Extract this ZIP file.
2. Push the code to a new **GitHub repository**.
3. Connect your repository to **Render.com** (for Backend) and **Vercel** (for Frontend).
4. Set your `MONGO_URI` environment variable.
5. Point your custom domain (`.com.np` or `.com`) to your frontend deployment!
